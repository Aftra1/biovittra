# Biovittra - Prothèses Innovantes

Site professionnel de Biovittra, une entreprise spécialisée dans la conception et la fabrication de prothèses de haute qualité.

## Caractéristiques

✅ **Responsive Design** - Optimisé pour tous les appareils  
✅ **SEO Optimisé** - Optimisé pour les moteurs de recherche  
✅ **Performance** - Chargement rapide et fluide  
✅ **Design Moderne** - Interface professionnelle et attrayante  

## Sections

- **Accueil** - Présentation générale avec call-to-action
- **À propos** - Historique et valeurs de l'entreprise
- **Produits** - Catalogue des 4 types de prothèses
- **Avantages** - 6 points forts de Biovittra
- **Contact** - Formulaire de contact et infos de contact

## Déploiement

Ce site est hébergé sur GitHub Pages.

```bash
git clone https://github.com/aftra/biovittra.git
cd biovittra
```

## Fichiers

- `index.html` - Page principale
- `robots.txt` - Instructions pour les moteurs de recherche
- `sitemap.xml` - Plan du site pour Google

## Optimisation SEO

- Meta tags (title, description, keywords)
- Open Graph tags pour les réseaux sociaux
- Structure HTML sémantique
- Responsive design (mobile-friendly)
- Sitemap.xml pour l'indexation
